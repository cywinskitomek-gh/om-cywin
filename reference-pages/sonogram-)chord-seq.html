SONOGRAM->CHORD-SEQ

[GENERIC-FUNCTION]
om-cywin

ARGUMENTS:
  - grid amplitude windows (output 1 of goertzel-sonogram)  
  - midics midicents (output 2 of goertzel-sonogram)  
  - times window onsets in ms (output 3 of goertzel-sonogram)  
&key
  
  - range-db

  - dur    
  - chan    

Description:

Turns the outputs of GOERTZEL-SONOGRAM into a CHORD-SEQ: each window is one chord.
Velocity is computed in decibels: the loudest component in the whole sound = 127,
<range-db> dB below it = 0 (default 40; at 40 dB: -10 dB -> 95, -20 dB -> 64, -30 dB -> 32).
<min-vel> notes with a lower velocity are skipped (default 1, i.e. only zeros).
<dur> note length in ms (nil = the distance between windows), <chan> MIDI channel.
